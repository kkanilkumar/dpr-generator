For the cleanest PDF

In the print dialog that opens next, for best results:

  • Set Destination to "Save as PDF"
  • Set Paper size to A4
  • Turn "Headers and footers" OFF — otherwise the browser prints its own date/time, page title and file path in the margins of every page
  • Turn Background graphics ON
  • Set Margins to "Default" or "None"
